# Pressure

`Pressure` is a browser prototype for an underwater extraction shooter. You descend through three facility levels, steal experimental tech, fight sea creatures and rival divers, and try to escape while pressure, darkness, hallucinations, and suit flooding get worse.

## Features

- Three handcrafted levels with escalating pressure
- Harpoon combat against creatures and hostile divers
- Dynamic pressure effects that reduce movement and destabilize the UI
- Suit crack state that slowly floods the visor
- Light radius shrink and hallucination phantoms at deeper levels

## Run Locally

Open [index-pressure.html](./index-pressure.html) in a browser.

Or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` or `http://localhost:8000/index-pressure.html`.
